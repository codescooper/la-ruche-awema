# Relecture métier — Développement — réalisation reproductible

- Le rendu respecte les décisions Designer, pas seulement les noms de fichiers.
- Build et lancement sont reproductibles avec dépendances réellement disponibles.
- CTA, navigation, focus et états fonctionnent.
- Aucun chargement externe non autorisé ni secret livré.
- Responsive, mouvement réduit et repli WebGL prévus si applicables.
- Rapport distingue tests DEV, tests QA et publication.

Cette checklist ne prouve pas son exécution. Citer uniquement les contrôles réellement faits.
