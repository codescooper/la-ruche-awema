# Relecture métier — Finance — analyse budgétaire assistée

- Même périmètre et devise pour tous les comparatifs.
- Budgets, engagements, paiements, trésorerie séparés.
- Aucun double comptage ni financement déduit d’une marge.
- Données inconnues et hypothèses explicites.
- Revue humaine requise pour les décisions financières.

Cette checklist ne prouve pas son exécution. Citer uniquement les contrôles réellement faits.
